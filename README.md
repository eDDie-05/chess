# Chess Game

A classic **Chess Game** developed as a programming project. The game allows two players to play chess on an 8×8 board while following the standard movement rules of the chess pieces.

## Features

* 8×8 chess board
* Two-player gameplay
* White and Black pieces
* Legal piece movement
* Turn-based gameplay
* Capture system
* Check detection
* Checkmate detection
* Stalemate detection
* Castling
* Pawn promotion
* En passant
* Game restart functionality

## Chess Pieces

Each player has:

* 1 King
* 1 Queen
* 2 Rooks
* 2 Bishops
* 2 Knights
* 8 Pawns

## How to Play

1. White moves first.
2. Players take turns moving one piece at a time.
3. Each piece follows its specific movement rules.
4. Players can capture opposing pieces.
5. The objective is to place the opponent's king in **checkmate**.
6. The game ends when a checkmate or draw condition occurs.
